# 开源人形机器人生态调研报告

> 调研时间：2026-10-30
> 数据来源：GitHub REST API 实测（24 个仓库，2026-10-30 查询）+ 中文媒体交叉验证 + 各项目 BOM 文件逐项核对
> 关联项目：OTTO 123（K12 创客教育机器人，晚托班 / 学校社团课 / C 端周末班）
> 核心问题：2026 年底开源人形机器人生态到了什么程度？哪些对 OTTO 123 有直接借鉴价值？

---

## 1. 调研目标

2026 年下半年开源人形机器人领域出现多个高热度项目，社交媒体上「很火的开源人形机器人」的说法指向多个不同对象。本报告需要回答：

1. **哪些项目是真的开源人形机器人本体**，哪些只是开源模型 / 数据集 / 工具链
2. **热度是否属实**——用 GitHub star、fork、许可证、提交活跃度做硬指标核验，不采信媒体形容词
3. **复刻成本**——一台机器人到底要花多少钱，用各项目官方 BOM 核算
4. **对 OTTO 123 的意义**——是威胁、是机会、还是可以直接抄的课

**结论先行**：最火的 Microduck 不是人形（是鸭形双足）；真正的全开源人形本体只有 3 个。两者对 OTTO 123 的成本结构都不构成竞争威胁，但**开源 RL 训练闭环与中文教程生态是可迁移的课程资产**。

---

## 2. 三层分类框架

开源人形生态混杂着「本体 / 模型 / 数据 / 工具」四种东西，先分清楚才能对比：

| 层级 | 包含什么 | 代表项目 | 对教育产品的直接价值 |
| --- | --- | --- | --- |
| **L1 本体层** | 完整机器人硬件 + 控制 / 训练代码全开源 | Roboto Origin、天工 3.0、Microban、灵犀 X1 | 极高（可复刻即课程载体） |
| **L2 消费爆款层** | 低价整机 + 软件栈开源 | Microduck（鸭形）、XGO-Duck | 中（形态非人形，但便宜） |
| **L3 软件生态层** | 仿真器、基础模型、数据集、教程 | MuJoCo、LeRobot、Isaac GR00T、every-embodied | 高（课程素材来源） |

## 3. L1 本体层：真正开源的人形机器人

### 3.1 RoboParty 萝博头 ROBOTO_ORIGIN ★2784

上海萝博派对科技有限公司（2025-02-21 成立）原型机，2026-01-15 全栈开源，同步启动全球开发者共创计划。

**GitHub 实测**：`Roboparty/roboto_origin` · star **2784** · fork 389 · **GPL-3.0** · 建仓 2025-12-31 · 最后提交 **2026-10-29**（活跃）· Python

**开源范围**：机械结构 CAD、PCB 设计、ROS2 驱动、强化学习训练环境、URDF/MJCF 运动学描述、固件、导航模块，共 7 个子仓库聚合（`rpo_hardware` / `roboparty_deploy` / `roboparty_train` / `rpo_description` / `roboparty_firmware` / `rpo_appearance` / `roboparty_navigation`）。

**技术栈**：ROS2 Humble + Isaac Sim 4.5.0 + Isaac Lab 2.1.1 + rsl_rl + Python 3.10 + C++17

**成本（官方 BOM 实测）**：**¥49,713**，70 个零件，结构件小计 ¥15,670，CNC 加工为主（大腿内衬 ¥1500×2、髋关节固定 ¥1800、小腿 ¥1600×2），其余为 48V 15Ah 锂电与天猫 / 淘宝件（每项均附采购链接）。

**判断**：这是**工业级开源，不是教育级**。BOM 是 OTTO 123 基础版（≤250 元）的 199 倍，官方定位是记录来时路，因为「一台高性能的机器人远远不是手搓所能达到的」。对 OTTO 123 的价值在**规范参考**（模块划分、训练 / 部署分离、BOM 文档粒度），不在硬件本身。

### 3.2 天工 3.0（北京人形机器人创新中心）

2026-02-10 发布，169cm / 62kg，本体与数据集双开源。天工 Lite / Pro 提供 URDF、STEP 机械图纸、SDK（电机 / IMU / 六维力 / 相机接口）、基于 ROS 的天工软件系统（body_control / robot_description / usb_sbus）。

**RoboMIND 数据集**：479 种任务、96 类物体、10.7 万条真实世界演示轨迹。

**判断**：正规开源范本，适合做**行业认知层**的课程素材（顶尖团队怎么开源），不适合做硬件参考。

### 3.3 智元灵犀 X1（稚晖君 2024-10-24 开源）

29 个关节（自研 PowerFlow PF86 / PF52 关节），资料总量超 1.2G、230 张图纸，含 AimRT 平台组件、URDF、Sim2Sim 代码、强化学习训练代码、运控推理代码与调试工具。GitHub：`gibot_x1_hardware` / `gibot_x1_infer` / `gibot_x1_train`。

**关键信号**：智元官方明确表示，希望灵犀 X1 开源后能在教育领域发挥重要作用，让学生直接接触最前沿的机器人技术。这是行业头部厂商首次公开把教育列为开源目的。

**判断**：时间偏老（2024 年），但是**唯一被厂商官方定位为教育用途的本体级开源项目**，可作为「教育可用性」论证的先例引用。

### 3.4 Microban（波尔多大学 LaBRI）★641

Rhoban 团队的 Marc Duclusaud 设计，**30cm 高**，19 自由度，Dynamixel XL330-M288-T 总线舵机 ×19 + Raspberry Pi Zero 2W + Pollen RPI Robot Hat（自制 PCB，设计文件开源）。

**成本（BOM 实测）**：机器人本体 **$567**；加配置工具（Dynamixel U2D2 + Power Hub）**$623**。单舵机 $23.90 × 19 = $454，占成本 80%。全部零件带购买链接，约 30 个打印件，PLA 打印。

**许可证（关键约束）**：软件 GPLv3，**硬件 CC BY-NC-SA 4.0 —— 禁止商业使用**。

**热度**：$567 的「全 3D 打印 + 100% 开源人形」，被 hysenlabs 评为开源硬件从爱好玩物真正变成实验室愿意发给学生的样板。

**判断**：**形态和成本带最接近桌面级教育机器人**（30cm 桌面伴侣，与 OTTO 123 桌面形态同构），但 19 个 Dynamixel 单价 23.9 美元，舵机成本 3 倍于 OTTO 123 全部 BOM 之和；且硬件 NC 条款**直接封死商业化路径**。可作为形态标杆和 BOM 透明度标杆参考。

### 3.5 元点机器人 OpenBridge / BRIDGE + FlowMimic

与 CMU 合作发表两篇论文（BRIDGE 开源硬件设计方案 + FlowMimic 开源指令控制框架），2026-09 正式发布开发者全开源生态。

**成本**：BRIDGE 硬件成本 **$1500**，对标 Toddy 的 $6000（约 1/4）。

**商业验证**：截至 2026-04 Zeroth M1 预订单近 2 万台；7 月整体订单破 3 万台；上半年营收同比 +600%；成立一年半累计融资 10 亿元。

**判断**：目前**唯一同时开放代码 + 开放设计 + 支持协同设计**的平台，自称人形机器人的安卓时刻。属于远期竞争观察对象。

## 4. L2 消费爆款层：Microduck 及其复刻潮

### 4.1 Microduck（机器鸭）—— 社交媒体上「很火」的那个

Hugging Face 旗下 Pollen Robotics 出品。前身是工程师 Antoine Pirrone 的个人开源项目 Open Duck Mini（GitHub 2600+ star），2025-04 被 HF 收购，2026-07-29 正式建仓，2026-08-27 开启全球预购。

**GitHub 实测**：`pollen-robotics/microduck` · star **13058** · fork 1616 · **Apache-2.0** · 最后提交 2026-10-29 · Rust

**规格**：25cm 高、<800g、15 个舵机、RK3566 主控、摄像头 + 深度雷达 + 双 IMU；鸭嘴是可开合夹爪，能叼起马克笔；摔倒可自主翻身；可装轮子滑行、可组队踢球。

**软件栈开源程度**：SDK、MuJoCo 仿真环境、完整 RL 训练管线、7 个出厂行为策略全部公开（Apache 2.0），官方鼓励用户训练新行为回传社区。官方示例可并行 4096 个仿真环境，CUDA GPU 上一套可用步态训练约 **1-2 小时**，然后 sim-to-real 部署回真机。

**销量实测（媒体交叉验证）**：开售 24 小时订单额破 **260 万美元**，峰值**每 4 秒卖出一台**，官方公告社区订了太多鸭子，发货排期拉长至 4-6 个月。国内代购闲鱼 ¥3680、淘宝 ¥5798。

**它是人形吗**：**不是**。25cm 鸭形双足，被业内称为具身智能领域的树莓派时刻。媒体标题里的「开源机器人」成立，「开源人形机器人」不成立。

**热度结论**：star 13058 是本次调研全部候选中**唯一破万的本体项目**，热度属实。

这是本次调研最有价值的发现——热度已经转化为**可复刻的国产供应链方案**：

| --- | --- | --- | --- | --- |
| `LuwuDynamics/xgoduck_hardware` | 1603 | 未声明 ⚠️ | Arduino UNO Q + 15× Feetech 1910 + 8.4V 18650 | 建仓 2026-09-24，硬件 / 运行 / RL 三仓分离 |

**飞特复刻版 BOM 实测（元）**：打印件 33 项共 **139 元**（淘宝成品打包）；外购件 23 项含 Radxa Zero 3W 309 / 64GB TF 60 / 树莓派 HAT 120 / imu_to_dxl 80 / **飞特 HD1901M ×15 = 1425** / URT2 调试板 45 / NP-F550 电池 47 / IMX219 摄像头 46.8 / VL53L8CX ToF 49.5 等，**合计约 2500 元**。

### 4.3 XGO-Duck（乐享机器人）

把 Microduck 改成 Arduino 方案：Arduino UNO Q + 15 颗 Feetech 1910 舵机 + 自制扩展板（含 IMU 与舵机接口），可打印结构件，官方电子套件在售，配套 runtime 与 RL 训练仓库。

**判断**：Microduck 复刻潮证明了一件事——**几百到两千多元、能走能站能自己爬起来、能被学生改动作的双足平台，是真实且旺盛的需求**。但它服务的群体是极客 / 高校 / 创客，不是 K12 晚托班。

**这个结论反而提示了一个机会**：低价 + 可复刻 + 可教学的双足平台，中文社区已经用 2500 元把它做出来了——说明**低成本可复刻具身平台的技术门槛已经被跨过**，OTTO 123 未来若要升级到双足行走，供应链是现成的。

## 8. 对 OTTO 123 的意义

### 8.1 风险

**R1 · 上游 OttoDIY 已停更。** `Open-Hardware-Leaders/OttoDIY` 仅 12 star，最后提交 2021-11-27，五年无更新。OTTO 123 事实上已经独自承担这条教育硬件线——这不是新风险，但意味着**所有结构改版、BUG 修复、供应链变更都要自己做**，没有社区兜底。建议在技术架构文档中显式记录，避免团队误以为有上游支持。

**R2 · 许可证混用风险。** Microban 硬件 CC BY-NC-SA（禁商用）、XGO-Duck 与飞特复刻版**无任何许可证声明**、灵犀 X1 与天工均为厂家自定条款。若未来引入这些项目的图纸或代码，NC 条款会直接击穿晚托班 / 周末班的商业模型，而「无声明」在法律上等于保留全部权利。**引入任何开源结构件前必须逐个核对许可证，这是硬门槛。**

**R3 · 热度正在向可复刻转化。** Microduck 三个月内出现三个中文复刻仓库且其中一个已实机跑通。头部开源项目 + 中文社区 + 淘宝供应链的组合，正在把几百元双足行走机器人变成常规商品。**如果我们的 L4 / L5 课程卖点是「唯一能走的中学生机器人」，这个叙事 12 个月内会失效。**

### 8.2 机会

**O1 · RL 训练闭环是现成的课程资产。** Microduck 的完整链路——MuJoCo 建仿真 → 并行 4096 环境训练步态（GPU 1-2 小时）→ sim-to-real 部署 → 学生改奖励函数重新训练 → 社区分享新行为——**这是一个极完整的 L3 / L4 课程闭环**，而且完全不需要买机器人硬件，纯 PC + 仿真环境即可开课。`every-embodied` 已把 VLA / OpenVLA / SmolVLA / Pi0 的从零构建全部教程化，中文、Python 基础门槛。

**O2 · 仿真器底座免费且成熟。** MuJoCo（Apache-2.0，15966 star）作为课程工具无授权成本，可直接用于 AI 决策教学环节。

**O3 · 复刻潮验证了国产供应链。** 飞特 HD1901M ×15 = 1425 元 + 淘宝 139 元打印件套包 + 嘉立创打样自制 PCB——**这套打法（国产舵机 + 淘宝打印件 + 嘉立创打样）与我方硬件路线完全同构**，可以直接复用其 BOM 文档组织方式：飞特版 BOM 已细到「哪个紧固件是平尾 M2×6、哪个是圆头 M3×16」，还附螺钉形状对照图——**这个文档粒度值得抄进我们的装配文档规范**。

**O4 · 厂商开源目的是教育。** 智元明确把教育领域发挥作用写进灵犀 X1 开源目的，天工开源自带完整 SDK 与 ROS 软件系统。**这意味着头部资源在向教育侧倾斜，未来谈合作有抓手。**
