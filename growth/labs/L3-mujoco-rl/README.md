# L3 实验课 · OTTO 机器人在电脑里活过来（MuJoCo 仿真 + 强化学习）

> 建立时间：2026-10-30
> 目标学员：12-14 岁，完成 L2 或 Python 基础较好
> 课时：2 次 × 90 分钟（可压缩为 1 次 120 分钟）
> **零硬件成本** —— 一台普通笔记本即可开课，不需要买机器人

---

## 一、这门课为什么存在

OTTO 123 的实物课程走到 L3 会撞上一堵墙：**真机只有 6 个舵机，走路是预先编排的动作序列，学生改不了"为什么这样走"**。

而仿真打开了一扇门：

- 仿真里的 OTTO 有真实的物理（重力、摩擦、扭矩限制），它会**真的摔倒**
- 学生可以无限次试错，摔坏的是虚拟的
- 学生可以修改**目标**（奖励函数），看机器人行为如何改变

本课的核心不是"教机器学习"，而是让学生亲眼看到一件事：

> **RL 不是魔法，是"目标定义 + 试错"的工程。**
> 你想让机器人走多远，取决于你怎么定义"走"。

## 二、实测数据（本机 16 核 CPU，无 GPU，2026-10-30）

| 指标 | 实测值 | 对教学的意义 |
|---|---|---|
| MuJooco 安装 | 12 秒 | 课上现装不超时 |
| 无头物理仿真 | 226,286 步/秒（452× 实时） | 6 秒的仿真 0.013 秒跑完 |
| gymnasium 随机步 | 20,362 步/秒 | 10 万步 ≈ 1 分钟 |
| OTTO 环境随机步 | 29,677 步/秒 | 回合足够密 |
| Tier A 网格搜索 | 240 组参数 / 0.5 秒 | 全班可以各跑一遍 |
| PPO 训练速度 | 3,528 步/秒 | 40 万步 = 1.9 分钟 |
| 离屏渲染 | ❌ 本机全黑（EGL/OSMesa/Xvfb 均不通） | **必须用数据图代替视频** |

### 关键实验结果（诚实记录）

**Tier A 手写步态 + 网格搜索**（`01_gait_search.py`）

- 240 组参数，0.5 秒跑完
- 最优组合：A=0.15 / B=0.80 / freq=1.6 / phase=2.36 → 位移 **+31.8cm**
- 但**站立时长只有 0.7 秒** —— 它是"扑倒着往前挪"，不是走路

**Tier B PPO 强化学习**（`02_train_ppo.py`）

| 阶段 | 结果 |
|---|---|
| 随机策略基线 | 20 回合平均回报 **-9.479**（几乎立刻摔倒） |
| 训练 40 万步后 | 回报爬到 **216**，评估平均回报 47.57 |
| 但位移 | 平均仅 **1.5cm**，正向回合均值 8.6cm，最远 9.9cm |

**结论（也是这堂课最有价值的部分）**：PPO 在 2 分钟内学会了**"不摔倒"**，但**没学会"往前走"**。

这不是失败，这是**最好的教学素材**：

1. 40 万步 = 1.9 分钟 → 学生完全跑得起，实时看到学习曲线
2. "学会站稳"和"学会走路"是两个难度台阶 → 直观展示 RL 的**探索难度**
3. 立刻引出下一课的动作：**改奖励函数**（把存活权重调低、速度权重调高），看机器人是否开始往前挪

## 四、环境准备（课前 1 周，教师操作）

```bash
# 教师机 / 学生机通用
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 验证（应输出 5000 步用时约 0.2 秒）
python -c "from otto_env import OttoWalkEnv; e=OttoWalkEnv(); print('环境就绪')"
```

**注意事项**：

- 不需要 GPU。**不要**安装 torch 的 CUDA 版本（stable-baselines3 会自动拉 CPU 版，约 200MB）
- 离屏渲染在无显卡/服务器上会全黑，**这不是 bug**，本课设计就是不看视频看数据
- 若教室电脑有独立显卡并想看画面，可装 `opencv-python` 并改用 `mujoco.viewer` 交互窗口（但**不要**在教学流程中依赖它）
